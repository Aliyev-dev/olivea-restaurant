# Olivea — Modern Mediterranean Restaurant

A polished, fully responsive restaurant website built with **React 18**, **Vite**, and **Tailwind CSS**.

🔗 **Live demo:** https://Aliyev-dev.github.io/olivea-restaurant/

## Features

- **Sticky navbar** with transparent-to-solid transition on scroll and a mobile menu
- **Full-screen hero** with call-to-action buttons and smooth-scroll navigation
- **About** section with stats
- **Interactive menu** with category tabs (Starters / Mains / Desserts / Drinks)
- **Gallery** grid with hover zoom and guest testimonials
- **Reservation form** with date/time/guest selection and a success confirmation state (front-end only)
- **Footer** with hours, location and contact details
- Mobile-first, responsive at every breakpoint, accessible focus styles

## Tech stack

- React 18 + Vite
- Tailwind CSS (custom theme: colors, fonts, animations)
- Plain, component-based structure — no backend

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
